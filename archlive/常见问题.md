# 常见问题速查

## `Repository not found` 但仓库明明存在

**九个半是证书吊销检查失败，不是权限、不是仓库不存在。**

Git for Windows 用 schannel 做 HTTPS，会去访问证书的吊销列表（CRL/OCSP）。
那些服务器被墙/被网关拦了 → 握手失败 → Git 报出误导性的 "Repository not found"
（因为 GitHub 对无权限的私有仓库也是返回 404，git 区分不出来）。

**解法：**

```bash
git config --global http.schannelCheckRevoke false
```

验证：

```bash
curl -sS -o /dev/null -w "%{http_code}\n" https://github.com
curl: (35) schannel: ... CRYPT_E_NO_REVOCATION_CHECK     ← 症状
返回 200                                                    ← 修好之后
```

curl 想绕过的话加 `--ssl-no-revoke` 或 `-k`：

```bash
curl --ssl-no-revoke -sS https://example.com
```

**怎么区分"证书问题"和"真的没权限"：**

```bash
curl -sS -o /dev/null -w "%{http_code}\n" https://github.com/<用户>/<仓库>
```

| 输出 | 含义 |
|---|---|
| `curl: (35) schannel: ...` | 证书吊销检查失败 → 用上面的解法 |
| `000` + 超时 | 网络不通 → 需要代理 |
| `404` | 仓库真不存在，或私有且没权限 |
| `200` | 仓库可访问，问题在 git 凭据 |

## push 时反复弹 "please complete authentication in your browser"

Git 凭据被拒了（可能缓存了坏的），清掉重来：

```bash
git config --global credential.helper reset
git config --global credential.helper manager
bash build/push.sh
```

凭据授权页面上如果**没勾"私有仓库"**，那只能推公开仓库。私有仓库要么改成 Public，
要么去 <https://github.com/settings/connections/applications> 给
Git Credential Manager 补上 Private repositories 权限。

## Git Bash 里 Ctrl+V 没反应

老毛病。用 **右键** 粘贴，或 **Shift + Insert**。

---

## 授权页/登录页没样式（白底黑字很丑）

GitHub 的 CSS 没加载。不影响功能，照常填就行。实在不行用设备码登录：
Git 窗口里点 **Sign in with a code**，然后在浏览器打开
<https://github.com/login/device> 粘码。

---

## CI 里包名校验失败

```
FAIL  任何地方都找不到: xxx
```

说明 `packages.x86_64` 里写了仓库里没有的包名。跑：

```bash
bash build/preflight.sh .
```

它会对着当天的官方仓库数据库逐个核对。

---

## 装机后进不去图形界面

Live 里（或装好后用 TTY 登录，`Ctrl+Alt+F2`）：

```bash
systemctl status display-manager
journalctl -b -u display-manager -n 50
cat /var/log/shorin-install.log
cat /var/log/shorin-remove-kde.log
cat /var/lib/shorin-incomplete      # 存在 = 上次安装有失败项
```
